# Simulador de ritmos cardíacos

Monitor de ECG animado (25 mm/s, 6 s en pantalla) para practicar la identificación de ritmos:

- **Con pulso:** sinusal, bradicardia, taquicardia, TSV, FA, flutter 2:1 y 4:1, BAV de 1.er grado, Mobitz I, Mobitz II, BAV completo y marcapasos.
- **Parada:** FV, TV sin pulso, asistolia y AESP, indicando si son desfibrilables.
- **Modo examen:** muestra un ritmo al azar y oculta el nombre hasta que aciertas o pulsas «Revelar».
- **Sincronizar:** marca cada onda R como haría el desfibrilador antes de una cardioversión.

## Usarlo como aplicación

Abre la página publicada en GitHub Pages y:

- **iPhone (Safari):** Compartir → «Añadir a pantalla de inicio».
- **Android (Chrome):** menú ⋮ → «Instalar aplicación».

Funciona sin conexión una vez abierta.
